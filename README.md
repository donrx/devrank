# devrank
Scan your computer to determine your developer rarity

## Installation & Usage:
This program require python to run
```bash
git clone https://github.com/donrx/devrank.git
cd devrank
python devrank.py
```

## Rarity:
- Slop
- Common
- Uncommon
- Rare
- Epic
- Legendary
- Mythical
- Ascended
- Cosmic
